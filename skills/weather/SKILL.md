# Weather

Read the current conditions for a city. This skill runs on the host. The guest has no network.

Examples:

- What's the weather in Seattle?
- 今天天气怎么样
- 上海天气

If the message does not name a city, SSIOS uses the city saved in Settings. Units are metric. The card shows the place, temperature, conditions, and wind. Open-Meteo does not need an API key.
