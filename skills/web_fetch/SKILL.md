# Web fetch

Fetch one address the user wrote. Only `GET` over `http` or `https`. No cookies, no authorization header, and no request body.

SSIOS resolves the name and checks every address before connecting, including after a redirect. Loopback, private, link-local, and similar addresses are refused. Scripts are removed. The text is marked untrusted and is not allowed to start a tool, a connector write, or the guest.

The card shows the title, the site name, a short extract, and a link.
